## AgentRuntime characterization (current V1 behavior, before refactor)

- RT-C01 idempotent start same key/request; mismatched request rejected.
- RT-C02 durable append-before-publish; strictly ordered replay after sequence; dedupe and gap recovery.
- RT-C03 cancel and repeated cancel, queued/running/waiting-approval.
- RT-C04 resume matching engine/run binding only; stale/foreign checkpoint rejected.
- RT-C05 agent approval pause/resume not document approval; permission revocation not bypassed.
- RT-C06 tool invocation ledger records retried and unknown external outcomes correctly.
- RT-C07 failure/restart during provider stream and tool execution; no fictitious terminal success.
- RT-C08 prepared request 95,000 and serialized final JSON 100,000-character boundaries tested before outbound provider call.

Characterization tests distinguish **current observed behavior** from **desired target behavior**; failing current behavior should be documented, not falsified to pass.
